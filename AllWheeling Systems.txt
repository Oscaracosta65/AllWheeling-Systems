        [[h2 class="le-section-heading" style="margin-top:14px"]]What a wheeling system does[[/h2]]
        <p>
          A wheeling system is a predefined combination template.
          Given a pool of numbers, the system determines how those numbers
          are grouped into lines so coverage is distributed across combinations
          in a structured way.
        </p>

        <p>
          Different systems trade off simplicity, total lines, and coverage depth.
          This library lets you compare those structures before committing to one.
        </p>

        [[h2 class="le-section-heading" style="margin-top:14px"]]How this fits into LottoExpert[[/h2]]
        <p>
          On LottoExpert.net, wheeling systems are part of a broader analytical toolkit.
          You select a system here, then open it in the
          <a href="/wheel-builder1">Wheel Builder</a> to
          generate combinations using your own selected numbers.
        </p>

        <p class="le-muted">
          SKAI-powered analysis tools help interpret patterns and distributions elsewhere
          on the platform. Wheeling systems themselves are neutral combination structures
          and do not predict outcomes or change probability.
        </p>

          [[/li]]

    [[h2 class="le-faq-section-heading"]]Wheeling Systems: Common Questions[[/h2]]

    [[details class="le-faq-item"]]
      [[summary]]What is a lottery wheeling system?[[/summary]]
      [[p class="le-faq-answer"]]
        A wheeling system is a predefined combination template. Given a pool of numbers
        you choose, the system determines how those numbers are grouped into playable
        lines so coverage is distributed across combinations in a structured way. It is
        a coverage organization tool, not a prediction tool.
      [[/p]]
    [[/details]]

    [[details class="le-faq-item"]]
      [[summary]]Do wheeling systems improve my odds of winning?[[/summary]]
      [[p class="le-faq-answer"]]
        No. Wheeling systems do not increase your overall odds of winning. They organize
        your combinations so that if your selected numbers contain the drawn numbers,
        your coverage guarantee is met. The underlying probability of each individual
        line remains unchanged. Wheeling helps you manage coverage within a fixed budget
        of lines, not change probability.
      [[/p]]
    [[/details]]

    [[details class="le-faq-item"]]
      [[summary]]What does the assurance or guarantee column mean?[[/summary]]
      [[p class="le-faq-answer"]]
        The assurance indicates the minimum prize tier you are guaranteed to win if a
        specific number of drawn numbers fall within your selected pool. For example,
        a <strong>3-if-4</strong> guarantee means you are assured at least one 3-number
        match if any 4 of the drawn numbers are among your selections. Higher assurances
        generally require more combinations.
      [[/p]]
    [[/details]]

    [[details class="le-faq-item"]]
      [[summary]]What is the difference between a full wheel and an abbreviated wheel?[[/summary]]
      [[p class="le-faq-answer"]]
        A full wheel generates every possible combination from your selected numbers,
        providing maximum coverage but also the highest number of lines and cost.
        An abbreviated (or reduced) wheel uses fewer combinations while still maintaining
        a defined coverage guarantee, making it more practical for most players and budgets.
      [[/p]]
    [[/details]]

    [[details class="le-faq-item"]]
      [[summary]]What does the Games column tell me?[[/summary]]
      [[p class="le-faq-answer"]]
        The Games column shows the total number of combinations (lines) the system
        generates. This directly corresponds to how many tickets you would need to
        purchase to play the full system. Compare this against your intended budget
        before selecting a system.
      [[/p]]
    [[/details]]

document.addEventListener('DOMContentLoaded', function() {
  'use strict';

  // Same JSON source currently used in production.
  var INDEX_URL = '/media/lottoexpert/wheels/wheels-index.json?v=' + Date.now();

  // Current production builder route.
  var ENGINE_BASE = '/wheel-builder1';

  // Future SEO detail route.
  // Leave disabled until the detail pages are deployed.
  var DETAIL_BASE = '/wheeling-system';
  var USE_DETAIL_PAGE = false;

  var data = [];
  var filteredData = [];

  var pickSizeSelector = document.getElementById('pickSize');
  var numberRangeSelector = document.getElementById('numberRange');
  var assuranceSelector = document.getElementById('assurance');
  var resultsTable = document.getElementById('resultsTable');
  var tableBody = resultsTable.getElementsByTagName('tbody')[0];
  var statusBox = document.getElementById('leCatalogStatus');

  function escapeHtml(value) {
    var div = document.createElement('div');
    div.textContent = value == null ? '' : String(value);
    return div.innerHTML;
  }

  function safeInt(value) {
    var parsed = parseInt(value, 10);
    return isNaN(parsed) ? 0 : parsed;
  }

  function buildActionUrl(item) {
    if (USE_DETAIL_PAGE === true) {
      return DETAIL_BASE + '/' + encodeURIComponent(item.system_id);
    }

    return ENGINE_BASE + '?system_id=' + encodeURIComponent(item.system_id);
  }

  function populateDropdown(selector, optionsArray, forcedValue) {
    var force = (forcedValue != null) ? String(forcedValue) : 'All';
    var exists = { 'All': true };
    var i;
    var option;
    var value;

    selector.innerHTML = '<option value="All">All</option>';

    optionsArray = optionsArray || [];

    for (i = 0; i < optionsArray.length; i++) {
      value = String(optionsArray[i]).trim();

      if (!value) {
        continue;
      }

      exists[value] = true;

      option = document.createElement('option');
      option.value = value;
      option.textContent = value;
      selector.appendChild(option);
    }

    selector.value = exists[force] ? force : 'All';
  }

  function refreshSelectUI(selectEl) {
    try {
      var parent;
      var nice;
      var evt;

      if (!selectEl) {
        return;
      }

      parent = selectEl.parentNode;

      if (parent) {
        nice = parent.querySelector('.nice-select');
        if (nice && nice.parentNode) {
          nice.parentNode.removeChild(nice);
        }
      }

      evt = document.createEvent('HTMLEvents');
      evt.initEvent('change', true, false);
      selectEl.dispatchEvent(evt);
    } catch (e) {
      // Silent by design for production stability.
    }
  }

  function populateAllNumberRanges() {
    var map = {};
    var uniqueRanges = [];
    var i;
    var key;

    for (i = 0; i < data.length; i++) {
      map[data[i].numberRange] = true;
    }

    for (key in map) {
      if (Object.prototype.hasOwnProperty.call(map, key)) {
        uniqueRanges.push(safeInt(key));
      }
    }

    uniqueRanges = uniqueRanges.filter(function(n) {
      return n > 0;
    }).sort(function(a, b) {
      return a - b;
    });

    populateDropdown(numberRangeSelector, uniqueRanges, 'All');
  }

  function populateAllAssurances() {
    var map = {};
    var uniqueAssurances = [];
    var i;
    var key;
    var assuranceValue;

    for (i = 0; i < data.length; i++) {
      assuranceValue = String(data[i].assurance || '').trim();
      if (assuranceValue) {
        map[assuranceValue] = true;
      }
    }

    for (key in map) {
      if (Object.prototype.hasOwnProperty.call(map, key)) {
        uniqueAssurances.push(key);
      }
    }

    uniqueAssurances.sort();

    populateDropdown(assuranceSelector, uniqueAssurances, 'All');
  }

  function displayData(rows) {
    var i;
    var item;
    var tr;
    var td;
    var link;
    var fragment;
    var linkLabel;

    tableBody.innerHTML = '';

    if (!rows.length) {
      tr = document.createElement('tr');
      td = document.createElement('td');
      td.colSpan = 5;
      td.textContent = 'No systems match the current filters. Try clearing one or more filters.';
      tr.appendChild(td);
      tableBody.appendChild(tr);
      return;
    }

    fragment = document.createDocumentFragment();

    for (i = 0; i < rows.length; i++) {
      item = rows[i];
      tr = document.createElement('tr');

      td = document.createElement('td');
      td.textContent = item.pickSize;
      tr.appendChild(td);

      td = document.createElement('td');
      td.textContent = item.numberRange;
      tr.appendChild(td);

      td = document.createElement('td');
      td.textContent = item.assurancePlain || item.assurance || '';
      if (item.assuranceTitle) {
        td.title = item.assuranceTitle;
      }
      tr.appendChild(td);

      td = document.createElement('td');
      td.textContent = item.games;
      tr.appendChild(td);

      td = document.createElement('td');
      link = document.createElement('a');
      link.href = buildActionUrl(item);
      link.textContent = (USE_DETAIL_PAGE === true) ? 'View Details' : 'View System';
      linkLabel = ((USE_DETAIL_PAGE === true) ? 'View Details' : 'View System') +
        ': Pick ' + item.pickSize +
        ', ' + item.numberRange + ' numbers' +
        (item.assurancePlain ? ', ' + item.assurancePlain : '');
      link.setAttribute('aria-label', linkLabel);
      link.target = '_blank';
      link.rel = 'noopener noreferrer';
      link.className = 'le-btn secondary';
      td.appendChild(link);
      tr.appendChild(td);

      fragment.appendChild(tr);
    }

    tableBody.appendChild(fragment);
  }

  function updateNumberRangeDropdown() {
    var psVal = String(pickSizeSelector.value || 'All');
    var psNum = (psVal === 'All') ? null : safeInt(psVal);
    var possibleRows = [];
    var map = {};
    var uniqueRanges = [];
    var i;
    var nr;
    var key;

    for (i = 0; i < data.length; i++) {
      if (psNum === null || safeInt(data[i].pickSize) === psNum) {
        possibleRows.push(data[i]);
      }
    }

    if (!possibleRows.length) {
      populateAllNumberRanges();
      return;
    }

    for (i = 0; i < possibleRows.length; i++) {
      nr = safeInt(possibleRows[i].numberRange);
      if (nr > 0) {
        map[nr] = true;
      }
    }

    for (key in map) {
      if (Object.prototype.hasOwnProperty.call(map, key)) {
        uniqueRanges.push(safeInt(key));
      }
    }

    uniqueRanges = uniqueRanges.filter(function(n) {
      return n > 0;
    }).sort(function(a, b) {
      return a - b;
    });

    if (!uniqueRanges.length) {
      populateAllNumberRanges();
      return;
    }

    populateDropdown(numberRangeSelector, uniqueRanges, 'All');
    refreshSelectUI(numberRangeSelector);
  }

  function updateAssuranceDropdown() {
    var psVal = String(pickSizeSelector.value || 'All');
    var nrVal = String(numberRangeSelector.value || 'All');
    var psNum = (psVal === 'All') ? null : safeInt(psVal);
    var nrNum = (nrVal === 'All') ? null : safeInt(nrVal);
    var possibleRows = [];
    var map = {};
    var uniqueAssurances = [];
    var i;
    var assuranceValue;
    var key;

    for (i = 0; i < data.length; i++) {
      if (psNum !== null && safeInt(data[i].pickSize) !== psNum) {
        continue;
      }
      if (nrNum !== null && safeInt(data[i].numberRange) !== nrNum) {
        continue;
      }
      possibleRows.push(data[i]);
    }

    if (!possibleRows.length) {
      populateAllAssurances();
      refreshSelectUI(assuranceSelector);
      return;
    }

    for (i = 0; i < possibleRows.length; i++) {
      assuranceValue = String(possibleRows[i].assurance || '').trim();
      if (assuranceValue) {
        map[assuranceValue] = true;
      }
    }

    for (key in map) {
      if (Object.prototype.hasOwnProperty.call(map, key)) {
        uniqueAssurances.push(key);
      }
    }

    uniqueAssurances.sort();

    if (!uniqueAssurances.length) {
      populateAllAssurances();
      refreshSelectUI(assuranceSelector);
      return;
    }

    populateDropdown(assuranceSelector, uniqueAssurances, 'All');
    refreshSelectUI(assuranceSelector);
  }

  function filterTableData() {
    var psVal = String(pickSizeSelector.value || 'All');
    var nrVal = String(numberRangeSelector.value || 'All');
    var aVal = String(assuranceSelector.value || 'All');
    var psNum = (psVal === 'All') ? null : safeInt(psVal);
    var nrNum = (nrVal === 'All') ? null : safeInt(nrVal);

    filteredData = data.filter(function(item) {
      var ps = safeInt(item.pickSize);
      var nr = safeInt(item.numberRange);
      var as = String(item.assurance || '').trim();

      if (psNum !== null && ps !== psNum) {
        return false;
      }
      if (nrNum !== null && nr !== nrNum) {
        return false;
      }
      if (aVal !== 'All' && as !== aVal) {
        return false;
      }

      return true;
    });

    displayData(filteredData);
  }

  function clearFilters() {
    pickSizeSelector.value = 'All';
    populateAllNumberRanges();
    populateAllAssurances();
    numberRangeSelector.value = 'All';
    assuranceSelector.value = 'All';
    filteredData = data.slice();
    displayData(filteredData);
  }

  function attachDropdownListeners() {
    pickSizeSelector.addEventListener('change', function() {
      if (pickSizeSelector.value === 'All') {
        populateAllNumberRanges();
        populateAllAssurances();
        numberRangeSelector.value = 'All';
        assuranceSelector.value = 'All';
      } else {
        updateNumberRangeDropdown();
        numberRangeSelector.value = 'All';
        populateAllAssurances();
        assuranceSelector.value = 'All';
      }

      filterTableData();
    });

    numberRangeSelector.addEventListener('change', function() {
      if (numberRangeSelector.value === 'All') {
        populateAllAssurances();
        assuranceSelector.value = 'All';
      } else {
        updateAssuranceDropdown();
      }

      filterTableData();
    });

    assuranceSelector.addEventListener('change', filterTableData);

    document.getElementById('clearFilters').addEventListener('click', clearFilters);
  }

  function attachSortListeners() {
    var ths = resultsTable.querySelectorAll('th.sortable');
    var i;

    for (i = 0; i < ths.length; i++) {
      (function(th) {
        function doSort() {
          var type = th.getAttribute('data-type');
          var isAscending = !th.classList.contains('asc');
          var cols;
          var k;

          filteredData.sort(function(a, b) {
            var va = a[type];
            var vb = b[type];

            if (type === 'assuranceSort') {
              va = String(va || '');
              vb = String(vb || '');
              return isAscending ? va.localeCompare(vb) : vb.localeCompare(va);
            }

            va = safeInt(va);
            vb = safeInt(vb);

            return isAscending ? (va - vb) : (vb - va);
          });

          cols = resultsTable.querySelectorAll('th.sortable');
          for (k = 0; k < cols.length; k++) {
            cols[k].classList.remove('active', 'asc', 'desc');
            cols[k].setAttribute('aria-sort', 'none');
          }

          th.classList.add('active');
          th.classList.add(isAscending ? 'asc' : 'desc');
          th.setAttribute('aria-sort', isAscending ? 'ascending' : 'descending');

          displayData(filteredData);
        }

        th.addEventListener('click', doSort);

        th.addEventListener('keydown', function(e) {
          var code = e.keyCode || e.which;
          if (code === 13 || code === 32) {
            e.preventDefault();
            doSort();
          }
        });
      })(ths[i]);
    }
  }

  fetch(INDEX_URL, { credentials: 'same-origin', cache: 'no-store' })
    .then(function(r) {
      if (!r.ok) {
        throw new Error('HTTP ' + r.status);
      }
      return r.text();
    })
    .then(function(t) {
      var txt = (t || '').trim();
      var j;

      try {
        j = JSON.parse(txt);
      } catch (e) {
        throw new Error('JSON parse failed. First chars: ' + txt.slice(0, 80));
      }

      if (!j || !j.items || !j.items.length) {
        throw new Error('Catalog empty or missing items[]');
      }

      data = j.items.map(function(it) {
        var sysId = (it.system_id != null) ? it.system_id : (it.id != null ? it.id : '');
        var ps = (it.pickSize != null) ? it.pickSize : (it.pick_size != null ? it.pick_size : 0);
        var nr = (it.numberRange != null) ? it.numberRange :
                 (it.requiredSelections != null ? it.requiredSelections :
                 (it.number_range != null ? it.number_range : 0));
        var as = (it.assurance != null && String(it.assurance).trim() !== '') ? it.assurance :
                 (it.assuranceText != null && String(it.assuranceText).trim() !== '') ? it.assuranceText :
                 (it.assurance_text != null ? it.assurance_text : '');
        var asPlain = (it.assurance_plain != null && String(it.assurance_plain).trim() !== '') ? it.assurance_plain :
                      (it.assurancePlain != null && String(it.assurancePlain).trim() !== '') ? it.assurancePlain :
                      as;
        var asTitle = (it.assurance_title != null && String(it.assurance_title).trim() !== '') ? it.assurance_title :
                      (it.assuranceTitle != null && String(it.assuranceTitle).trim() !== '') ? it.assuranceTitle :
                      '';
        var g = (it.games != null) ? it.games :
                (it.combinationsCount != null ? it.combinationsCount :
                (it.combinations_count != null ? it.combinations_count : 0));

        return {
          system_id: String(sysId || ''),
          pickSize: safeInt(ps),
          numberRange: safeInt(nr),
          assurance: String(as || '').trim(),
          assurancePlain: String(asPlain || '').trim(),
          assuranceTitle: String(asTitle || '').trim(),
          assuranceSort: String(asPlain || as || '').trim().toLowerCase(),
          games: safeInt(g)
        };
      });

      data = data.filter(function(r) {
        return r.system_id && r.pickSize > 0 && r.numberRange > 0;
      });

      if (!data.length) {
        throw new Error('Catalog parsed but contains 0 valid systems.');
      }

      filteredData = data.slice();

      (function buildPickDropdown() {
        var pickMap = {};
        var pickSizes = [];
        var key;
        var i;

        for (i = 0; i < data.length; i++) {
          pickMap[data[i].pickSize] = true;
        }

        for (key in pickMap) {
          if (Object.prototype.hasOwnProperty.call(pickMap, key)) {
            pickSizes.push(safeInt(key));
          }
        }

        pickSizes = pickSizes.filter(function(n) {
          return n > 0;
        }).sort(function(a, b) {
          return a - b;
        });

        populateDropdown(pickSizeSelector, pickSizes, 'All');
      })();

      pickSizeSelector.value = 'All';
      populateAllNumberRanges();
      populateAllAssurances();
      numberRangeSelector.value = 'All';
      assuranceSelector.value = 'All';

      displayData(filteredData);
      attachDropdownListeners();
      attachSortListeners();

      (function setStatusOk() {
        var dot = document.querySelector('.le-dot');
        if (dot) {
          dot.classList.add('ok');
        }
      })();

      statusBox.textContent = 'Loaded ' + data.length + ' systems. Use the filters to find yours.';
    })
    .catch(function(err) {
      var dot = document.querySelector('.le-dot');

      if (dot) {
        dot.classList.remove('ok', 'warn');
        dot.classList.add('err');
      }

      statusBox.textContent = 'Could not load wheel catalog: ' + err.message;
    });
});
